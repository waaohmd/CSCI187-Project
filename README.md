# Campus Community Marketplace

A web app for students to buy and sell used items or request moving and delivery help.

## Features

- Create, edit, sell, and remove item listings.
- Search and filter marketplace listings.
- Create, edit, and remove moving or delivery requests.

## Prerequisites

- PHP 8.1+
- Node.js 20+

## Setup

1. Run `git clone https://github.com/waaohmd/CSCI187-Project.git`.
2. Run `cd CSCI187-Project`.

## Run

Run `php -S localhost:8080 -t .`.

Open [http://localhost:8080](http://localhost:8080).

## Test

Run `npm run check` for syntax checks and unit tests.

Start the PHP server, then run `npm run test:api` for API integration tests.
